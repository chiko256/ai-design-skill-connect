# AIデザインSkill 接続専用クライアント

この公開リポジトリに含むのは、接続設定の例、認証付き取得・更新プログラム、導入案内のみです。
Figma操作、画像処理、生成支援、検査などの補助プログラムと制作手順は含みません。

有効な契約者トークンを使ってMCPサーバーから制作クライアントを取得します。GitHubアカウントや非公開GitHubへの招待は不要です。

## 新規導入

このリポジトリを `~/.codex/skills/web-design-pro` へcloneし、`SETUP_WITH_AI.md`をCodexに読ませてください。

## 既存のお客さん

MCP接続先と既存の契約者トークンはそのまま使えます。MCP契約情報に返される移行案内に従い、このリポジトリのインストーラーで現在のSkillフォルダを更新してください。ローカルの変更・Figmaの.runtime・案件ファイルは保全します。GitHubの旧履歴をresetする必要はありません。

## 配布の仕組み

公開されるのはこの接続専用コードです。補助プログラムの取得・更新には契約認証が必要です。取得済みコードの回収や、受領した人による再配布を技術的に完全防止する仕組みではありません。

WindowsのPowerShellではPython 3.11以降で`scripts/private-client.py`を直接実行できます。.shや追加シェルは不要です。新規設定はWindows資格情報マネージャーを使い、認証保存後に更新・接続を確認します。
